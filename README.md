# e-plantShopping

A responsive React-based e-commerce web application for a houseplant shopping store. Built using modern web technologies and Redux for state management, allowing users to browse plants, manage their shopping cart, and seamlessly update quantities or remove items.

## Features

- **Product Catalog:** Browse a wide variety of houseplants categorized with images, pricing, and descriptions.
- **Shopping Cart Management:** 
  - Add plants to the cart.
  - Dynamically increment or decrement item quantities.
  - Automatically calculate the total cost per item and total cart amount.
  - Remove items from the cart seamlessly.
- **State Management:** Powered by Redux Toolkit for efficient and centralized cart state management.
- **Navigation:** Easily switch between the landing page, product listing, and the shopping cart page.

## Tech Stack

- **React.js** (Functional Components, Hooks)
- **Redux / Redux Toolkit** (State Management)
- **CSS3** (Styling and Layout)
